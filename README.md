# *Library Management - Core*

---

### 🎯 Objective

The main goal of this project is to use it as a learning environment to improve my understanding of software development, going beyond simply implementing features and focusing on learning how to structure an application in an organized, maintainable, and scalable way.

Throughout the development process, this project will serve as a foundation for studying programming concepts, object-oriented programming, software architecture, business rules, and Java best practices.

### Features:

- [x] Register users
- [x] Register books
- [x] Register book copies
- [x] Borrow a book copy
- [x] Return a book copy
- [x] Check book availability
- [x] View user borrowing history
- [ ] Prevent invalid loans

---

### What Is It?

This project consists of developing a library management system in Java, created with the goal of practicing and deepening my knowledge of software development and object-oriented programming.

The application simulates basic library operations, such as managing users, books, book copies, and loans.

The project is being developed incrementally, with an initial focus on Java fundamentals and the proper organization of responsibilities within the application.

Some of the main concepts explored in this project include:

- Object-Oriented Programming;
- Encapsulation;
- Relationships between objects;
- Interfaces and abstractions;
- Repository Pattern;
- Service Layer;
- Business rules;
- Data validation;
- Entity state management;
- Separation of concerns;
- Code organization and software architecture;
- Java development best practices.

---

### Technologies:

- Java 21 and Maven
- In-memory data storage
- No frameworks or external databases

This approach allows me to initially focus on building the application's logic, defining entity behavior, and understanding the separation of responsibilities between the different layers of the system.
