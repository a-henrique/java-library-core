- [ ] Cadastrar exemplares de um livro
- [ ] Emprestar exemplar
- [ ] Devolver exemplar
- [ ] Consultar disponivilidade
- [ ] Consultar historico do usuario
- [ ] Impedir emprestimos invalidos
